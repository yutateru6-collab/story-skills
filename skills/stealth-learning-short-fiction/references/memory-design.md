# Memory Design Without Turning the Story Into a Lesson

The goal is not to force memorization during reading. The goal is to make each target sentence easier to retrieve later because it is attached to a vivid narrative context.

## 1. One sentence, one memorable anchor

Attach each target to at least one strong anchor:

- emotion: embarrassment, fear, relief, jealousy, pride, regret
- action: serve, run, delete, hide, open, miss, fall, wait
- object: umbrella, phone, ticket, key, notebook, scoreboard
- image: empty gym, unread message, wet shoes, dark stairwell
- relationship: rival, friend, sibling, coach, parent, crush
- reveal: "the person knew all along", "the message was not a mistake", etc.

Avoid giving several sentences the same weak anchor.

## 2. Meaning before form

The scene should make the sentence's meaning intuitively obvious before the reader reaches the Japanese translation.

The translation confirms meaning; the surrounding story supplies context.

Do not rely on grammar labels for memory.

## 3. Retrieval cue principle

After reading, a useful mental path is:

scene -> meaning -> English sentence

For example:

empty gym after practice -> "has continued for a period up to now" -> target present-perfect sentence

Do not expose this chain as a study diagram unless requested. It is an authoring principle.

## 4. Natural repetition across an anthology

Do not repeat the exact same target three times in one short story unless the user asks.

Prefer distributed re-encounters across different stories or later exercises:

- Story A: target appears in full
- Story B: same grammar meaning appears in a different context
- Test mode: original sentence returns with a blank

This keeps fiction natural while strengthening retrieval.

## 5. Distinctive beats beat decorative spectacle

A sentence is not memorable merely because the setting is dramatic.

A small, specific emotional beat can be stronger than elaborate worldbuilding:

- someone left half a donut for a friend
- a rival has been arriving ten minutes earlier every morning
- a deleted message appears again at 2:13 a.m.

Choose specificity over spectacle.

## 6. Contrast can strengthen understanding

When the source material teaches a contrast, stories may place two meanings near each other if it remains natural.

Examples:

- routine vs action happening now
- finished past vs connection to the present
- earlier past vs later past reference point
- spontaneous decision vs prior plan

Do not force contrast into every story.

## 7. Keep the target rare enough to stand out

English should feel visually special because the surrounding prose is Japanese.

If English appears too frequently, the target loses salience and the story begins to feel like a worksheet.

## 8. Use emotion honestly

Do not add tragedy, romance, horror, or danger solely because "emotion improves memory". The selected genre must still feel coherent and age-appropriate.

The story should earn the emotional beat.

## 9. Scene-to-test bridge

When the user later requests practice, reuse the exact source sentence in test form rather than inventing a loosely similar item.

Possible sequence:

1. read story
2. recall scene
3. see exact sentence with one or more blanks
4. reconstruct target
5. optionally show the original scene snippet again

This bridge belongs to practice mode, not automatically to every story output.

## 10. Memory QA

For each target ask:

- Can I name the specific scene attached to this sentence?
- Is that scene different enough from the other target scenes?
- Does the scene embody the sentence's meaning accurately?
- Is there an unnecessary grammar explanation doing work the scene should do?
- Would the target still be retrievable from the scene after a delay?

If the answer to the first three is weak, redesign the scene rather than adding more explanation.
